v0.0.2 // ACTIVE OS KERNEL / BARE-METAL

Atobold (Atobold 0.0.2)

A small 32-bit x86 educational operating system kernel built from first principles—"retrial of an OS". Transitions from a custom 512-byte BIOS boot sector in 16-bit real mode into a freestanding 32-bit protected-mode C kernel.

Boot Pipeline 512B MBR (`INT 13h`) → GDT setup → 32-bit Protected Mode at 0x9000
Interrupts & Faults Custom IDT configuration, low-level ISR stubs, & CPU exception register dumps
Hardware Drivers Polled 16550 UART Serial (COM1) headless debugging & 0xB8000 80x25 VGA text console
C (Freestanding) x86 NASM Assembly GNU Linker Script QEMU / GDB Makefile
